Overflow Properties in CSS

overflow: visible

This is a long text demonstrating the visible overflow property. Content extends outside the box and remains visible.

overflow: hidden

This is a long text demonstrating the hidden overflow property. Extra content is clipped and cannot be seen outside the box.

overflow: scroll

This is a long text demonstrating the scroll overflow property. Scrollbars are always displayed even if they are not required.

overflow: auto

This is a long text demonstrating the auto overflow property. Scrollbars appear automatically only when the content exceeds the box size.
